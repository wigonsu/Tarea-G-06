## Práctica G-06 · Programación con JavaScript y el DOM

| Paso | Página | Script | Qué hace |

| 1 | `paso1.html` | `js/ejercicios.js` | Ejercicios de variables, operadores y estructuras de control (ver en F12 → Consola) |
| 2 | `paso2.html` | `js/costo.js` | Función `costoPaquete` que calcula el costo de un paquete turístico y lo muestra con `textContent` |

1. Abrir la carpeta en Visual Studio Code.
2. Abrir `index.html` con Live Server (o con doble clic).
3. Presionar F12 → Consola para ver los resultados del Paso 1.
